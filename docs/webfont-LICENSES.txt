Web fonts requested by index.html
=================================

The page requests three families from Google Fonts and falls back to system
fonts when the network is unavailable. No font files are redistributed in this
repository. Each family is licensed under the SIL Open Font License, Version
1.1; the full OFL text is retained once in ibm-plex-LICENSE.txt and applies to
all three.

Copyright and license lines below are quoted verbatim from each project's
OFL.txt, retrieved 2026-09-08.
