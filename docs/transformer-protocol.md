# Transformer protocol — declared before training

2026-09-08. One seed (0), one 2,200-step run; no extensions, restarts, seed selection or hyperparameter search. Activation ratios are not optimization targets.

Validity gate: finite tensors plus fixed canonical 77-token evaluation mean cross-entropy ≤ 1.6835368457 bits (1.5 × BDH's 1.1223578971), and target-aligned repeat CE ≤ 1.1492212212 bits (1.5 × BDH's 0.7661474808). These deliberately permissive predictive-comparability thresholds are our declared experimental decision, not a paper requirement. Failure makes the contrast inconclusive, regardless of its sparsity ratio. A single evaluation word does not establish population performance.

Architecture: d_model=32, 4 layers, 4 heads, vocabulary=32, d_ff=1024. One bias-free Q/K/V/O block and one bias-free ReLU FFN reused at every depth. Untied embedding and output matrices. Parameter-free LayerNorm (epsilon 1e-5). Normalize embedding, then at every depth: attention on current residual, residual add and LayerNorm, FFN h=ReLU(xW1), residual add and LayerNorm. Output xWout. No dropout. All trainable tensors initialized independently N(0,0.02), float32 CPU. Actual count: embedding/output 2,048 + attention 4,096 + FFN 65,536 = 71,680, versus BDH 100,352; equal measured neuron denominator does not mean equal parameter budget.

Scaled dot-product softmax attention includes diagonal 0. BDH uses an unnormalized strict diagonal -1 operator. This is a deliberate comparison asymmetry; strict causal softmax could instead be implemented with special empty-row handling. RoPE directly reuses bdh_probe.get_freqs and Attention.rope with theta=65536; Transformer head width 8 differs from BDH width 256. Reusing a formula does not remove this confound.

Import bdh_probe.py by adding its repository root, resolved from __file__, to sys.path. Import resets Python/Torch RNG and creates WARMUP. All subsequent generators are explicit. Build the original BDH model with its build_model() seed discipline and capture Torch RNG immediately afterward; replay the original torch.randint sampler with that state using a dedicated Generator, independent of Transformer initialization. Corpus uses original make_stream(400, random.Random(1)); canonical evaluation uses original make_cycle(random.Random(99)); labels and WARMUP are imported. This reproduces the baseline code's sampled batches, assuming the same Torch RNG implementation; archived baseline sampled indices do not exist to independently prove historical identity. Export the complete sampled-index schedule and its SHA256.

Training: batch 4, sequence 154, 2,200 steps, AdamW lr=0.003, betas=(0.9,0.999), eps=1e-8, weight_decay=0.01, amsgrad=False, no clipping/scheduler. CPU threads=2. Training loss nats, evaluation CE bits. Archive final minibatch loss as descriptive only; the gate uses evaluation CE.

Measurement: capture h before output projection, exact count(h>0), 1,024 neurons, all four depths and 77 tokens. Activity means exclude token 0, yielding warmup/memorize/repeat denominators 12/8/56. CE uses 76 next-token predictions and preserves both predictor-position and target-position labels; do not apply the activity mask to CE. Schema-versioned full hidden tensors and logits support parity checks. Untrained seed-0 weights are exported without optimization. Preserve all original BDH artifacts.

Checks: parameter count independent of depth; finite outputs; deterministic eval; causal future isolation; exact count/fraction agreement; correct phase denominators; export round-trip; sampler replay equality against original generator behavior. The offline result remains tied to the canonical preset and cannot respond to UI controls.
