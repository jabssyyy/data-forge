Why the meter moves

BDH · Definition 4
y(t,l) = (Dy·LN(a∗(t,l)))+ ⊙ x(t,l)

the readout gatethe neuron’s own activation

  1. y is the vector we count non-zeros in. It is two non-negative vectors multiplied element-by-element — a gate that needs both sides to be positive.
  2. When the recurrent state already predicts the next token, the left factor collapses toward zero and the gate closes. No sparsity setting causes this — the equation has no sparsity hyperparameter.
  3. In the pathwaycom/bdh implementation, Dy is the variable called encoder_v and E is called decoder. The weights are shared across all four layers — layer 2 behaves differently from layer 0 only because the residual stream has been transformed by the layers before it.

(Definition 4, Dragon Hatchling paper, arXiv 2509.26507, p.18). The variable measured here is xy_sparse, the gated product — not y_sparse, which is only the left factor before the gate.

What this does not show

7 disclosed limitations
  1. Layer 0 shows no effect — confirming the paper’s own statement about higher layers. Switch the layer control to 0 and watch the curve stay flat. The shipped run measured 0.92×; we report that as no effect, not as an inversion.
  2. 64× neuron shrink (65536 → 1024). The ratio reproduces; absolute levels differ — ours run roughly 3× the paper’s percentages.
  3. Synthetic task only — no claim is made about BDH on natural language. The corpus is a 13-letter warm-up plus a random 8-letter word, by design.
  4. Token 0 always reads 0.0% — attention is tril(diagonal=-1), so token 0 attends to nothing. A code property, not a finding. It is excluded from the warm-up mean on this page; the probe’s published 18.14% figure includes it.
  5. Independent reimplementation — faithful to pathwaycom/bdh with a measurement hook added and the config shrunk. Not an official BDH model.
  6. BDH-CQ (Engdahl et al., 2026) is a later reasoning system in the same family; the sparse-activation property here is a BDH result, not a BDH-CQ result. No public checkpoint exists, so BDH-CQ is cited and never run.
  7. Warm-up shows the highest activity, and we cannot say why. On the shipped run layer 2 sits at 18.14% through warm-up against 5.08% on repeats — yet the model’s cross-entropy on the warm-up is 0.113 bits, lower than the 0.766 bits it spends on repeats. Activity there tracks neither the oracle’s uncertainty nor the model’s. An earlier draft of this note explained the gap as “activity tracks the model’s uncertainty, not the oracle’s.” We measured that and it is false. It is corrected here rather than quietly dropped. The most plausible remaining explanation is state re-establishment at the start of a cold sequence — untested, and labelled as such. The claim in the bar above is scoped to the memorize → repeat transition precisely because of this gap.
