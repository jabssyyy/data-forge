# Submission checklist

Checked against the supplied Pathway brief, physical pages 11?14. The full 100-point rubric and evidence mapping are in the [evaluation guide](https://github.com/jabssyyy/data-forge/blob/main/documentation/evaluation-guide.md).

| Required item | Location |
|---|---|
| Public interactive artifact, no account | https://jabssyyy.github.io/data-forge/ |
| Public source repository | https://github.com/jabssyyy/data-forge |
| One-page concept PDF | [concept-summary.pdf](concept-summary.pdf) |
| Separate blog PDF | [blog.pdf](blog.pdf) |
| Complete README and local setup | [Technical README](../README.md) and GitHub root README |
| Three recent primary papers and nearby citations | [Sources](sources.md), PDFs and app |
| Code, data, weights, fonts, graphics, reuse and assistance disclosure | [Licenses and provenance](licenses.md), root README |
| Supporting narrated demo | documentation/demo/demo-final.mp4 in the GitHub repository |
| Reproduction checks | Node parity and memory tests; [verification index](https://github.com/jabssyyy/data-forge/blob/main/documentation/verification.md) |

Internal prompts, credentials, old demo versions and authoring caches are excluded. Keep only repo/ and documentation/ plus package README/LICENSE in the submission ZIP. A public push is not an event-portal submission. Team live defense and real-device evaluation remain human review activities.
